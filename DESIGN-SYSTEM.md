
# LinkVault Design System

## 1. Color Palette

| Color | Usage | Value |
|---|---|---|
| Primary | Main buttons and highlights | Violet (#7C3AED) |
| Secondary | Supporting elements | Slate (#1E293B) |
| Background | Main page background | Slate (#020617) |
| Text | Main text | White (#FFFFFF) |
| Accent | Links and highlights | Light Violet (#A78BFA) |
| Error | Delete actions | Red (#F87171) |
| Success | Success messages | Green (#4ADE80) |

## 2. Typography

- Font family: Default sans-serif
- Headings: Bold, large text
- Body: Regular, readable text
- Buttons: Medium or semibold text
- Small text: Smaller text for descriptions and labels

## 3. Reusable Components

- LinkCard: Displays a saved resource.
- Navigation: Helps users move between pages.
- Search Bar: Searches saved resources.
- Statistics Cards: Displays total links, categories and websites.
- Form Inputs: Used to enter link and profile information.
- Buttons: Used for adding, deleting and saving information.

## 4. Design Principles

- Simple and clean interface.
- Consistent colors across pages.
- Clear navigation.
- Responsive layout for different screen sizes.
- Easy-to-read text and buttons.
